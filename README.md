# MapPolygons — Райони Львова

Інтерактивна мапа районів Львова для пошуку житла: зелені зони — де хочу жити, червоні — які не рекомендують.

**Жива мапа:** https://taraschernysh.github.io/MapPolygons/

## Можливості

- 🟢🔴 Полігони районів з описом — клікніть на зону, щоб побачити нотатки.
- 🔎 Пошук адреси: введіть вулицю (наприклад, «Личаківська 45») — мапа покаже, у зеленій чи червоній зоні ця адреса.
- ✏️ Редагування: кнопка «Редагувати» вмикає інструменти малювання (нові полігони, зміна меж, видалення).
- 💾 Кнопка «Зберегти data.js» завантажує оновлений файл даних — замініть ним `data.js` у репозиторії та закомітьте, і мапа оновиться для всіх.

## Технології

Статичний сайт без збірки і без платних API: [Leaflet](https://leafletjs.com) + тайли OpenStreetMap + [Leaflet-Geoman](https://geoman.io) (редагування) + [Nominatim](https://nominatim.org) (геокодинг). Хостинг — GitHub Pages.

## Локальний запуск

Просто відкрийте `index.html` у браузері — сервер не потрібен.
